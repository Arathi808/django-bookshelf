About BookShelf

BookShelf is a simple book management web application developed using Python and Django.

Our Purpose

The purpose of this project is to make book management easier by allowing users to add, view, update and delete book information.

Features

  • Add new books
  • View all available books
  • View individual book details
  • Edit existing book information
  • Delete books
